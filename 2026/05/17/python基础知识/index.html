四、面向对象编程

1. 面向对象概述

面向对象简称OOP，把事物抽象成类，通过类创建对象，注重整体行为与特征。

  • 类：事物的抽象模板
  • 对象：类实例化出来的具体个体
  • 三大特性：封装、继承、多态

2. 类与对象基础

2.1 定义类

2.2 创建对象

2.3 self关键字

  • 代表当前实例对象本身
  • 只能写在类内部方法中
  • 用来绑定对象属性、调用自身方法

3. 构造与析构方法

3.1 init 构造方法

创建对象时自动执行，用来初始化属性

3.2 del 析构方法

对象被销毁时自动执行

4. 成员分类

4.1 实例属性

属于单个对象，不同对象互不影响，通过self.属性定义

4.2 类属性

写在类内、方法外，所有对象共享

4.3 实例方法

默认带self，只能由对象调用

4.4 类方法

使用@classmethod装饰，参数为cls，操作类属性

4.5 静态方法

使用@staticmethod装饰，无默认参数，和类、对象关联弱

5. 面向对象三大特性

5.1 封装

将属性和方法封装在类中，隐藏内部细节，对外提供访问接口

  • 私有属性：__属性名，外部无法直接访问

5.2 继承

子类继承父类所有属性和方法，代码复用

5.3 多态

不同子类调用同一个父类方法，呈现不同执行效果，依赖继承与方法重写

6. 常用内置魔法方法

五、常见内置库&常用内置函数

1. 常用内置库

1.1 datetime

日期时间工具，可获取当前时间、格式化时间、时间运算、格式转换

1.2 re

正则表达式库，实现字符串匹配、查找、替换、分割

1.3 os

操作系统交互库，实现文件、文件夹创建、删除、重命名、路径操作

1.4 math

数学运算库，提供开方、三角函数、取整、圆周率等运算

1.5 random

随机数库，生成随机整数、浮点数、随机选取、打乱序列

1.6 json

JSON数据处理库，实现字典与JSON字符串相互转换

2. 常用内置函数

2.1 基础类型相关

  • print()：控制台打印输出内容
  • len()：获取字符串、列表、元组等长度
  • max()：获取序列最大值
  • min()：获取序列最小值
  • type()：判断数据所属类型

2.2 序列类型相关

  • sorted()：对序列进行排序
  • enumerate()：同时获取索引和对应元素
  • zip()：合并多个序列元素
  • reversed()：反转序列
  • sum()：计算序列数值总和

2.3 逻辑操作相关

  • all()：全部条件成立返回True
  • any()：任意一个条件成立返回True
  • bool()：转为布尔类型
  • filter()：根据条件过滤序列元素

2.4 数值操作相关

  • abs()：求取数字绝对值
  • pow(x,y)：计算x的y次方
  • divmod()：返回商和余数
  • round()：浮点数四舍五入

2.5 字符串操作相关

  • ord()：字符转为ASCII码值
  • chr()：ASCII码值转为对应字符
  • str()：任意数据转为字符串类型
