接口自动化config配置层

一、config 层核心功能

1. 统一管理项目路径

自动计算项目根目录，所有日志、报告、输出文件路径都基于此，避免路径报错。

2. 环境地址集中配置

管理接口基础地址，切换环境只改一处，不用动测试用例。

3. 多数据库连接配置

支持双数据库连接：

  • 主业务数据库（3306）
  • 成绩校验专用数据库（3308）
    方便测试中做数据查询、结果校验。

4. 输出目录统一规划

日志、测试报告、运行结果统一存放，结构清晰。

5. Allure 测试报告配置

指定报告生成路径，与 pytest 无缝对接。

二、详细解释

  • 导入 Python 内置系统模块，用于处理文件/文件夹路径。

项目根目录路径（最重要的基础路径）

  • __file__：表示当前 settings.py 文件
  • os.path.abspath(...)：获取文件绝对路径
  • os.path.dirname(...)：获取上一级目录
  • 最终得到：项目根目录绝对路径
    所有后续路径都基于它拼接，保证项目可移植、不报错。

接口服务地址配置

  • base_url：主业务接口域名 + 端口
  • mcp_base_url：第三方/管理平台/其他服务地址
    作用：测试用例中不写死地址，方便切换测试/预发/生产环境。

主业务数据库连接信息
给项目中的数据库工具类（DbClient）使用，用于：

  • 查询接口执行后的数据是否正确
  • 测试前数据清理
  • 测试后结果校验

成绩模块专用数据库

  • 端口 3308，与主库分开
  • 专门用于成绩相关接口的数据校验
    体现项目支持多数据源、多库校验。

输出文件路径配置

  • OUTPUT_DIR：项目输出根目录
  • LOG_DIR：日志存放目录
  • REPORT_DIR：测试报告存放目录
    好处：所有运行产物统一管理，结构干净。

Allure 测试报告专用路径

  • ALLURE_RESULT_DIR：存放 pytest 运行原始数据
  • ALLURE_HTML_DIR：存放最终生成的网页报告
    必须与 pytest.ini 配置一致，否则报告无法生成。

三、config 层在项目中的作用总结

一句话定位

settings.py = 整个接口自动化项目的配置中心

核心价值

  1. 统一配置，便于维护
  2. 切换环境只需改一处
  3. 路径自动计算，不报错
  4. 双数据库支持，满足复杂校验
  5. 报告、日志统一输出
  6. 测试用例无硬编码，规范整洁
