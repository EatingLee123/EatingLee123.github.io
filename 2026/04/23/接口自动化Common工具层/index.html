接口自动化Common工具层

封装断言

整体介绍

提供统一、可复用、带日志和测试报告的断言能力，支持：

  • 安全解析接口 JSON 响应
  • 断言 HTTP 状态码
  • 批量断言接口返回字段（JSONPath）
  • 执行 SQL 并断言数据库结果
  • 统一入口，一键完成所有断言

模块导入与日志初始化

  • typing：提供类型注解，让代码更易读、更规范
  • allure：生成测试报告，标记断言步骤
  • Response：requests 库的接口响应对象类型
  • extract_json_path：工具函数，根据 JSONPath 提取接口返回字段
  • settings：框架全局配置文件
  • DbClient：数据库操作封装类
  • get_logger：获取日志对象
  • logger：创建当前模块的日志实例，用于打印关键信息

safe_response_json 函数解释

  • 功能：安全地将接口响应转为 JSON，避免非 JSON 响应导致程序崩溃
  • 参数：
    • response：接口响应对象
    • default：解析失败时返回的默认值
  • 逻辑：
    • 尝试执行 response.json()
    • 如果响应不是 JSON，捕获异常并打印警告
    • 返回默认空字典 {} 或用户指定默认值
  • 作用：提升框架健壮性

assert_status_code 函数解释

  • 功能：断言接口响应的 HTTP 状态码
  • 参数：
    • response：响应对象
    • expected_status：预期状态码
  • 逻辑：
    • 使用 allure.step 将步骤写入测试报告
    • 对比实际状态码与预期值
  • 作用：统一状态码校验，报告更清晰

assert_json_path_rules 函数解释

  • 功能：根据传入的规则列表，批量断言接口返回的 JSON 字段
  • 参数：
    • response：响应对象
    • json_path_rules：断言规则列表，包含 path 和 expected
  • 逻辑：
    • 如果没有规则，直接返回不执行
    • 安全解析 JSON
    • 遍历规则，通过 JSONPath 提取实际值
    • 逐一断言实际值 == 预期值
  • 作用：支持批量字段断言，简化用例编写

assert_db_rule 函数解释

  • 功能：执行 SQL 并断言查询结果的行数
  • 参数：
    • db_rule：数据库断言规则，包含开关、SQL、预期行数、数据库配置 key
  • 逻辑：
    • 如果未启用，直接返回
    • 根据 config_key 读取对应数据库配置
    • 创建数据库连接，执行 SQL
    • 断言结果行数
    • 无论成功失败，最终都会关闭连接
  • 作用：实现接口+数据库一体化断言，保证数据一致性

assert_response_by_rule 函数解释

  • 功能：整个断言模块的统一入口函数，最常用、最重要
  • 参数：
    • response：接口响应
    • assert_rule：完整断言规则（状态码、json_path、db）
    • expected_status：可选，外部传入状态码
  • 逻辑：
    • 确定最终预期状态码（优先级：传入值 > 配置值 > 默认200）
    • 依次执行：
      1. 状态码断言
      2. JSON 字段断言
      3. 数据库断言
  • 作用：测试用例只需要调用这一个函数，即可完成全套断言

全局变量类

整体介绍

这是专门用于在接口自动化测试中，跨用例、跨步骤传递临时数据，比如 token、用户ID、订单号、手机号等。

模块导入

  • 导入类型注解，用于标注数据类型，让代码更规范。

全局变量存储类

  • 这是一个静态类，不需要创建实例就能用
  • _data 是一个私有字典，用来存所有全局变量
  • 作用：贯穿整个测试过程，保存需要跨接口使用的数据

  • 功能：往全局字典里存数据
  • 参数：
    • key：数据名称（如 “token”）
    • value：数据值（如 “abc123”）

get 方法 —— 取数据

  • 功能：从全局字典里取数据
  • 参数：
    • key：数据名称
    • default：取不到时返回的默认值
  • 使用示例：

all 方法 —— 获取全部数据

  • 功能：返回当前所有全局变量
  • 一般用于日志、调试、查看全局变量

clear 方法 —— 清空所有数据

  • 功能：清空所有全局变量

工具函数

代码整体介绍

提供通用、高频、可复用的工具函数，支撑整个框架运行。包含：编码转换、时间、变量替换、YAML读取、JSONPath提取、全局数据写入、Excel用例分组等核心能力。

模块导入与日志

  • 导入系统库、类型注解、YAML解析库
  • 导入全局数据类、项目路径、日志工具
  • 初始化当前模块日志器

b64_encode base64编码

  • 功能：对字符串进行 base64 编码
  • 场景：接口参数需要加密传输时使用

b64_decode base64解码

  • 功能：对 base64 字符串解码
  • 场景：解析接口返回的加密内容

now_str 获取当前时间

  • 功能：获取格式化当前时间
  • 默认格式：年-月-日 时:分:秒
  • 场景：生成时间戳参数、日志时间、文件名

data_replace 递归变量替换

  • 功能：递归替换字典/列表/字符串中的 ${key}
  • 支持无限层级嵌套
  • 场景：接口参数关联，如 token{token} token{order_id}

load_yaml_case 读取YAML用例

  • 功能：加载项目中的 YAML 用例/配置文件
  • 自动拼接项目路径
  • 安全加载，防止脚本注入
  • 场景：读取接口用例、配置文件

extract_json_path 提取JSON字段

  • 功能：从 JSON 中根据 JSONPath 提取值
  • 支持：.data.list[0].id.data.list[0].id.data.list[0].id- 自带类型校验，报错清晰
  • 场景：提取接口返回值，用于关联或断言

apply_extract_rules_to_global_data 提取并写入全局变量

  • 功能：根据 extract 规则批量提取数据，并写入全局变量
  • 异常捕获，不影响主流程
  • 记录日志
  • 场景：登录提取token、下单提取order_id

build_flow_cases Excel用例分组（流程化）

  • 功能：把 Excel 中多行步骤，按场景ID分组
  • 自动按步骤号排序
  • 输出流程化用例结构
  • 场景：一条流程用例包含多个接口步骤
